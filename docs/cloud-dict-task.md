# 雲端任務規範：字典逐字檢查、補資料、整理相似字

給雲端 Claude 的完整工作規範（ZIP 版，沒有 git）。開始前依序讀完：

1. 本文件（任務、判斷標準、流程）
2. `docs/codex-dict-prompt.md`：字典欄位格式與書寫風格 1–37 條。**本文件和它衝突時，以本文件為準**（衝突處已在下面標出）。
3. `docs/similar-format.md`：相似字對的格式。
4. `docs/cloud-dict-example.json`：一批完整的範例（aboard 的修改＋aboard／abroad 字對），照這個品質寫。

## 0. 範圍與禁止事項

- **只改** `packs/dict/level1–6.json`、`packs/dict/similar/`、`packs/dict/review/`，全部透過 `scripts/dict_batch.py apply` 寫入，不要手動編輯這些 JSON。
- 這包只有字典資料和工具，沒有 App 程式；成果用 `pack` 打包交給使用者。
- 不新增、刪除字，不改拼字，不改級別。
- `phrases`（片語）：**原樣保留，不新增、不修改**。字典頁不再顯示片語，片語卡另外處理。
- `confusables`：原樣保留，**不新增**，可以當相似字的參考。新發現的易混字一律寫成相似字對。
- 讀者是準備學測的台灣高中生（CEFR B1–B2）。**寧可留空，也不要寫錯或編造。**

## 1. 每個字要做的三件事

一個字一次做完三件事，**不要分好幾輪**。apply 之後字會被標成已檢查，之後不會再出現。

### 1.1 檢查：找出錯誤並修正

逐欄看。以下都算錯誤，一定要改：

| 欄位 | 常見錯誤 | 怎麼改 |
|---|---|---|
| `meanings[].zh` | 字義錯、太偏（罕用義、古義、專業義排在前面）、大陸用語、寫成句子 | 改成學測常用義，依常用程度排序，2–10 字，用「；」分隔 |
| `meanings[].pos` | 詞性錯（例如把 adv. 標成 adj.） | 改成正確詞性；同一詞性只因中文不同而拆成兩個字義是可以的 |
| `examples` | 句子裡用的不是這個字義、文法錯、不自然、中式英文、翻譯腔 | 重寫 |
| `patterns` | 句型不存在或寫法不對（maintain to V） | 刪除或改正 |
| `collocations` | 不常見或不存在的搭配 | 刪除；不夠就補真的常用的搭配 |
| `commonErrors` | **錯句其實是對的**：例如 aboard 原本寫「We got aboard the bus 是錯的」，但 get aboard 是正確英文 | 刪除，換成真正的常見錯誤；找不到就留空 |
| `synonyms` | `note` 只寫「意思相近」、沒有說出差別；混進片語或層級差太多的字 | 重寫 `note`；第一個一定是目標字本身（第 26 條，刻意設計，不要刪） |
| `antonyms` | 不是真的反義 | 刪除 |
| `origin` | 字源是編的、沒有寫出原文 | 能確定就改正，不確定就改成空字串 |
| `breakdown`／`related` | 硬拆、同根字不同源（pineapple 不是 apple 的同根字） | 刪除或改正；拆不了就 `breakdownApplicable: false` |
| `phonetic` | 音標錯、不是美式 IPA | 改成美式 IPA，例 /əˈbɔːrd/ |
| 全部 | 簡體字、大陸用語（視頻、信息、質量、軟件、網絡） | 改成台灣用語（驗證器會擋簡體字） |

**判斷原則**：原文正確、只是寫法和你習慣的不同，**不要改**。只改錯的和缺的，這樣也比較省額度。

### 1.2 補齊

| 欄位 | 標準 | 和 codex-dict-prompt.md 不同之處 |
|---|---|---|
| `examples` | **每個字義 2 句**，情境要不同（例如一句校園、一句社會新聞或旅行），8–18 字，只用 7000 字範圍內的字，目標字可以用變化形 | 原本是 1–2 句，改成一定要 2 句 |
| `ext` | 「具體的本義 → 這個字義」，一行 20–35 字；虛詞（the、of）或真的沒有引申關係就留空 | 目前 72% 是空的，要盡量補 |
| `patterns` | 動詞、形容詞有常考句型就寫，每個附例句；名詞通常留空 | 同第 24 條 |
| `collocations` | 每個字義 2–4 個真的常用的搭配；沒有常用搭配的虛詞可以留空 | 同第 25 條 |
| `forms` | 動詞：三單 · 過去式 · 過去分詞（不規則才另外寫）· V-ing；名詞：不規則複數；再加常見派生詞。用「 · 」分隔 | 同第 30 條 |
| `origin` | 可以查證的才寫：1–2 句，寫出原文拼法和意思 | 目前 47% 是空的；不確定就繼續留空 |
| `commonErrors` | 台灣學生真的常犯的錯：介系詞、及物與不及物、可數與不可數、中式英文、詞性誤用。0–2 條 | 目前 70% 是空的，但**不要硬湊**。常用動詞、形容詞通常找得到，名詞多半沒有 |
| `breakdown`／`related` | 同第 19、20 條 | — |

長度、語氣、標點的規則一律照 codex-dict-prompt.md 第 1–21 條。

### 1.3 相似字：從候選裡挑出真的值得學的

`show` 會列出三種候選，每個候選附上分數、級別、中文字義和訊號標記：

| 標記 | 意思 |
|---|---|
| 共同中文:xx | 兩個字有相同的中文字義。中翻英時看到這個中文，最容易選錯，優先考慮 |
| 音近 | 讀音幾乎一樣，拼字卻不太像（accept／except） |
| 拼字規則 | 差在 ance/ence、able/ible、雙寫字母這類常拼錯的地方 |
| 字典標為反義 | 字典把它們列成反義。反向字組（borrow／lend、teach／learn、bring／take）很容易搞混，要考慮 |
| 只靠中文重疊 | embedding 沒排進前面，只因為中文一樣才列入，雜訊比較多 |
| （已有字對） | 另一個字已經寫過這組，**不要重寫** |

**收錄標準**（要符合至少一項）：
- 形近：拼字差 1–2 個字母，或字母順序對調，或只差字尾，高中生真的會看錯、拼錯。
- 義近：同一個中文對到兩個英文字，中翻英時會選錯（affect／influence、refuse／reject）。
- 反向字組：借入和借出、教和學、帶來和帶走。
- 用法差別是學測考點（rise 不及物、raise 及物）。

**不要收**：
- 只是同一類的東西（Monday／Tuesday、cat／dog、red／blue）。
- 只是主題相關（doctor／hospital、book／borrow）。
- 意思完全不同、拼字也不像的字。
- 純詞形變化（go／went）。
- 程度差太多、學生不會同時碰到的字（L1 的字配 L6 的罕用字），除非真的是經典混淆組。

**數量**：形近、義近各 **0–5 組**，寧缺勿濫。大多數字形近只有 0–2 組，義近 1–3 組。

**kind 怎麼填**：形近寫 `visual`、義近寫 `semantic`，兩種都是（rise／raise、affect／effect）寫 `both`。

**同族字**（economic／economical、historic／historical、sensible／sensitive）：只在學生真的常搞混時才收，kind 寫 `visual`。

**候選清單以外**：你確定很常搞混的字對也可以加（例如 steal／rob、say／tell／speak／talk），但兩個字都要在字典裡。

**字對內容的寫法**：
- `aZh`、`bZh`：只寫和這組比較有關的字義，前面加詞性，例「v. 影響」。
- `diff`：一兩句講出核心差別，30–60 字，直接陳述，不要寫「兩者很容易混淆」這種廢話。
- `points`：2–4 點，每點「面向：內容」，面向從這些選：詞性、及物與否、搭配、語氣或正式程度、使用情境、拼字、發音。
- `tip`：一句好記的記憶法。可以用拼字線索（aboard 裡有 board）、字首字母（Affect = Action），或畫面聯想。**想不到好的就寫最關鍵的判斷方式，不要硬編諧音。**
- `exA`、`exB`：各一句，8–16 字。兩句最好是同一種情境，才能看出差別；句子裡要真的有那個字。
- `score`：照抄候選分數；候選清單以外的字對填 0.5。
- `a`、`b`：小寫，**依字母順序**，a 排在前面。

## 2. 工具

```bash
python scripts/dict_batch.py status                          # 各級進度、字對數
python scripts/dict_batch.py show --level 3 --n 20           # 下一批 20 個還沒檢查的字
python scripts/dict_batch.py apply /tmp/b.json --dry-run     # 只驗證
python scripts/dict_batch.py apply /tmp/b.json               # 驗證後寫入；有錯誤整批不寫
python scripts/dict_batch.py check                           # 全部重新驗證
```

`apply` 的輸入格式（完整範例：`docs/cloud-dict-example.json`）：

```json
{ "level": 3,
  "words": [ 有修改的字：完整的單字物件，整筆取代原條目 ],
  "pairs": [ 這批新增的相似字對 ],
  "reviewed": [ 這批 show 出來的字全部列上，包括沒改的 ] }
```

- `words` **只放有改動的字**；沒改的字只列在 `reviewed`。
- 改一個字時要放完整條目（包括原樣保留的 `phrases`、`confusables`），因為會整筆取代。
- 驗證器會擋下：簡體字、缺中文或例句、同義字第一個以外又出現目標字、不是這個級別的字、字對的字不在字典裡、a／b 順序錯、字對缺欄位。
- 驗證器的警告（例句找不到那個字、points 數量不對）要看一下，確認沒問題再送。

## 3. 流程

1. 執行 `python scripts/dict_batch.py status`，從還沒完成的級別接著做。
2. 級別順序：**3 → 4 → 5 → 2 → 6 → 1**（學測最常考的先做）。
3. 每批 20 字：`show` → 逐字判斷 → 寫 `/tmp/b.json` → `apply --dry-run` → `apply`。
4. **每 5 批（100 字）執行 `python scripts/dict_batch.py pack`**，把產生的 `out/dict-result-*.zip` 提供給使用者下載，並回報進度（status 的輸出）。
5. 可以開子代理平行處理不同級別（進度與字對依級別分檔），但**同一個級別只能有一個代理在做**。交代子代理時，要它先讀完 START.md 列的 4 份文件。
6. 每做完一整級，跑 `check`，確認 0 錯誤。
7. 額度或對話快到上限時，先寫 `REPORT.md`（見第 5 節），再 `pack` 一次，然後停下來。

## 4. 每批送出前的自我檢查

- [ ] 每個字義都有 2 句例句，而且例句用的是那個字義。
- [ ] 沒有簡體字、大陸用語、Markdown 符號、表情符號。
- [ ] 不確定的字源、同根字、常見錯誤都留空，沒有編造。
- [ ] `commonErrors` 的錯句真的是錯的，對句真的是對的。
- [ ] 字對的兩個字都真的會被搞混，沒有收同類字或主題相關字。
- [ ] 沒動到 `phrases`、`confusables`。
- [ ] `reviewed` 列了這批全部的字。

## 5. 做完之後（或要停下來時）

在包的根目錄寫 `REPORT.md`（`pack` 會一起打包），內容：
- 各級檢查了幾字、改了幾字、新增幾組相似字（形近／義近／兩者）。
- 最常見的錯誤類型和例子，各 2–3 個。
- 還沒做完的級別、需要人工確認的字。
